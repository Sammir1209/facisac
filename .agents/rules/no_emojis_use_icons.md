# Regla de Diseño e Interfaz de Usuario: Prohibición de Emojis y Uso Obligatorio de Iconos

## Regla General
- **QUEDA ESTRICTAMENTE PROHIBIDO EL USO DE EMOJIS** en cualquier elemento visual de la interfaz de usuario, títulos, botones, alertas, tabs, modales o textos de estado del frontend (por ejemplo: prohibido usar ✅, ❌, ⚠️, ⏳, 🚫, 📅, ℹ️, 🚨, etc.).
- **USO OBLIGATORIO DE ICONOS SVG / LUCIDE-REACT**: Todos los estados, avisos, botones, badges y acciones deben utilizar componentes de iconos vectoriales limpios y estilizados (como `lucide-react` o equivalentes HeroUI: `CheckCircle2`, `AlertTriangle`, `Clock`, `ShieldAlert`, `FileCheck`, `Info`, `XCircle`, etc.).
- Mantener una estética enterprise, sobria, moderna y premium.
